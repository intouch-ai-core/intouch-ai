ClickHouse Tasks

InTouch Personal Edition v8.0.0

Overview

Runs SQL against a ClickHouse cluster over its HTTP interface (port 8123, or 8443 with TLS). No JDBC driver is involved — the HTTP interface handles queries, inserts and format conversion, which keeps the connector small and avoids driver conflicts.

Credential

Create a clickhouse credential:

FieldValue
ServerClickHouse host name or address
PortLeave 0 for the default: 8123, or 8443 when SSL is on
LoginClickHouse user (defaults to default)
SecretPassword (may be blank on an unsecured dev cluster)
DatabaseDefault database for statements that don't name one
SSLConnect over HTTPS — required by ClickHouse Cloud

The Test button runs SELECT version(), so a green result means the credentials actually authenticate — not merely that the port is open.

Operations

execute

Runs any SQL. A SELECT publishes rows (a JSON array of objects keyed by column name) along with columns, rowCount, rowsPublished and truncated. DDL and DML simply run.

Published rows are capped at maxRows, or 1000 when it isn't set, because outputs are held in memory and written to the activity log. rowCount is always the true number of rows returned; truncated tells you whether rows is the whole result. Use export for large result sets.

export

Streams a query result to a delimited file. ClickHouse performs the formatting and the response is written straight to disk, so the result never has to fit in memory and quoting is the server's own — values containing the delimiter, quotes or newlines are escaped correctly.

import

Loads a delimited file into a table. The file is sent as the body of an INSERT and parsed by ClickHouse. With a header row, columns are matched to the table by name, so the file's column order does not have to match the table's. Without a header, values are taken in the table's own column order.

list-databases, list-tables, describe

Catalogue browsing. list-tables takes a database; describe takes a database and a table and reports each column with its type.

Delimiters

comma and tab map to ClickHouse's CSV and TSV formats. pipe and other use CustomSeparated with the delimiter applied as a format setting. When other is chosen, a custom delimiter is required.

Extra settings

The settings field takes a JSON object of ClickHouse settings applied to the request, for example {"max_execution_time":"60"}.
