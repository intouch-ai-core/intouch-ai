Overview

Cassandra tasks execute CQL (Cassandra Query Language) statements against Apache Cassandra databases. They require a Cassandra connection configured with the cluster's contact points and credentials.

Task Configuration

PropertyDescription
ConnectionThe Cassandra connection to use
CQL StatementThe CQL statement to execute
KeyspaceThe Cassandra keyspace to operate in

Use Cases

  • Data Loading -- Insert or update data in Cassandra tables
  • Data Extraction -- Query Cassandra for reporting or further processing
  • Schema Management -- Execute DDL statements to manage Cassandra schemas
  • Maintenance -- Run maintenance operations on Cassandra clusters
